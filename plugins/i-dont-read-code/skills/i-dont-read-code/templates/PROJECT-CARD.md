# What you own

A standing record of the software you paid for, in terms you can use without me. Keep it in the
project root. Update it whenever any line changes; restate it at milestones.

This exists because the anti-dependency guardrail has to be *active*. A user who cannot describe,
price, or hand off their own software has been made dependent, however plainly it was explained to
them along the way. The stack and vendor names below are business facts — the kind you need to hire
someone, question an invoice, or move on.
